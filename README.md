## Login & Register — Authentication Portal

A modern, responsive authentication system built with clean HTML, CSS, and JavaScript. This project features a sleek user interface for user login and registration with smooth transitions, intuitive form validation, and an elegant dark-themed design.

## Features

- **User-Friendly Forms:** Clean, intuitive login and registration forms with proper input validation and error messaging.
- **Smooth Transitions:** Seamless page transitions between login and registration views with animated slide effects.
- **Responsive Design:** Fully responsive layout that adapts beautifully from mobile to desktop screens.
- **Form Validation:** Client-side validation for email format, password requirements, and required fields.
- **Modern Visual Design:**
  - Dark-themed aesthetic with gradient accents
  - Smooth hover effects and interactive buttons
  - Professional typography and spacing
  - Clear visual hierarchy

- **Password Management:** Toggle password visibility, password strength indicators, and confirmation matching.
- **Error Handling:** Real-time feedback for form errors with user-friendly messages.
- **Cross-Browser Compatible:** Works reliably across all modern browsers (Chrome, Firefox, Safari, Edge).
- **Fast & Lightweight:** Zero dependencies — pure HTML, CSS, and vanilla JavaScript for optimal performance.

## Technologies Used

- **HTML5:** Semantic form structure with accessibility attributes for better UX and SEO.
- **CSS3 (Vanilla):** Modern CSS with flexbox layouts, animations, transitions, and responsive media queries — no frameworks required.
- **JavaScript (Vanilla):** Handles form validation, DOM manipulation, state management, and user interactions without external libraries.
